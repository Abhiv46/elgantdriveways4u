# Elgant Driveways

Static marketing website for **Elgant Driveways** — printed concrete and imprint driveway specialists in Birmingham.

## Structure

| File / folder | Purpose |
| --- | --- |
| `index.html` | Single-page site (services, patterns, gallery, contact) |
| `images/` | Driveway pattern and completed-work photography (porcelain tile, herringbone brick, cobble, landscaping and concrete finishes) |

## Running locally

Open `index.html` in a browser, or serve the folder with any static server, e.g.:

```bash
npx serve .
```

No build step or dependencies are required.
